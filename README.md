# LifeOS — персональный ИИ-ассистент

Мобильное приложение-ассистент, который управляет задачами, привычками, финансами, календарём, поездками и памятью — через диалог на естественном языке. Вместо десятка отдельных приложений — один ИИ-агент, который понимает запрос и сам выполняет действие.

> Монорепозиторий: мобильное приложение (React Native / Expo) + backend (Node.js / Fastify / Prisma). ~66 000 строк TypeScript.

---

## Возможности

- **ИИ-агент с действиями.** Оркестратор интентов + executor с 21 исполняемым действием (создать задачу, отметить привычку, записать расход, добавить событие, построить маршрут и др.) через LLM tool-calling.
- **Голос и текст.** Голосовой ввод с fallback (нативное распознавание → Whisper) и текстовый чат.
- **Календарь.** Двусторонняя синхронизация с Google Calendar через OAuth 2.0 (pull + push, дедупликация событий).
- **Память.** Сервис памяти на PostgreSQL Full-Text Search — ассистент помнит людей, факты и контекст.
- **Проактивность.** Планировщик на сервере шлёт уведомления (Expo Push + Telegram-зеркало) с дедупликацией.
- **Финансы.** Учёт доходов/расходов, бюджет-анализ.
- **Геймификация.** Питомец, привычки, серии (streak), арена, награды.
- **Оффлайн.** Очередь мутаций и кэш — действия не теряются при потере сети и досылаются при восстановлении.
- **PDF-отчёты** и push-уведомления в мобильном клиенте.

---

## Технологии

**Mobile:** React Native (Expo), TypeScript, навигация на React Navigation, дизайн-токены, accessibility-метки.
**Backend:** Node.js, Fastify, Prisma ORM, PostgreSQL.
**AI:** Anthropic Claude API, агентная оркестрация, tool-calling, web-search, память на FTS.
**Интеграции:** Google Calendar (OAuth 2.0), Telegram Bot API, Expo Push.

---

## Архитектура

```
apps/mobile      — клиент на Expo: экраны, сторы, сервисы (offline-queue, api single-flight refresh)
packages/server  — Fastify API: 35+ роутов, 16+ сервисов
  ├─ services/jarvis-orchestrator   — маршрутизация интентов
  ├─ services/action-executor       — 21 исполняемое действие
  ├─ services/agent-tools           — LLM-инструменты с логикой к БД
  ├─ services/memory-service        — память (PostgreSQL FTS)
  ├─ services/proactive-scheduler   — проактивные уведомления
  └─ prisma/                        — схема БД
```

## Безопасность

- Шифрование чувствительных данных — **AES-256-GCM** (random IV, auth tag).
- Аутентификация — **JWT с ротацией refresh-токенов**, single-flight refresh на клиенте.
- Защита от **IDOR** — каждый CRUD-роут проверяет владельца записи (`findFirst({ id, userId })`).
- Rate-limiting на AI-эндпоинтах, серверная валидация игровых механик.
