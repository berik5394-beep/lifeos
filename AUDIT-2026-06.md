## Протокол
- Один пункт = аккуратный заход (понять → фикс → tsc/тест → локальный коммит). Push/deploy/flag — только по явному «пуш и деплой». Прод-БД не трогаем; миграции — локальный docker, на прод через `migrate deploy`.
- Принцип: битая не-ядровая фича → удаляем, не чиним. Verify по факту (БД/тест), не по нарративу.

**ИТОГО до сабмита, проходящего ревью:**
- гладко (Apple не упрётся): **~1.5 недели**
- реалистично (1–2 реджект-цикла по toxic/age/privacy): **~2–3 недели**
- если Apple жёстко по токсичной персоне: **3–4 недели**

🔑 **Главный риск/неизвестность — ревью «токсичного» AI-компаньона.** Чем мягче подадим toxic-режим (age-gate + явное согласие + не-вредит-в-кризисе), тем меньше циклов.
