# Робот-эпик, Часть 3: два экрана вместо вкладок, инструменты — панели

**Дата:** 2026-11-05 · **Решение Berik:** «Два экрана, панели из текущих» · **Опора:** заметка `mobile_ux_two_screen` (схема Berik 2026-06-01), Части 1–2 (робот + эмоции уже есть).

## Цель
Убрать 6 вкладок. Приложение = два экрана, между которыми свайп:
- **Комната** (слева): робот на переднем плане в своей комнате. В Части 3 — оболочка (робот, фон, подсветка по времени суток); мебель — Часть 4.
- **Рабочий** (справа, открывается по умолчанию): большой робот + чат с голосом. Инструменты спрятаны: кнопка «Инструменты» раскрывает ряд чипов; тап по чипу — или фраза «покажи задачи» — открывает панель.

## Панели
Панель = существующий экран, открытый как нативная шторка iOS (`presentation: 'modal'` в native-stack: рабочий экран с роботом уменьшается за шторкой, свайп вниз закрывает). Экраны не перерисовываем.

| Панель | Экран | Имя маршрута |
|---|---|---|
| Сегодня | `app/(tabs)/index.tsx` (бывший дашборд) | `Dashboard` |
| Задачи | `app/(tabs)/tasks.tsx` | `Tasks` |
| Привычки | `app/(tabs)/habits.tsx` | `Habits` |
| Цели | `app/(tabs)/goals.tsx` | `Goals` (по `ui-store` goals_tab) |
| Финансы | `app/(tabs)/finance.tsx` | `Finance` (по `ui-store` finance_tab) |
| Календарь | `app/calendar.tsx` | `Calendar` (уже есть) |
| Дневник | `app/journal` | `Journal` (уже есть) |

Имена маршрутов сохраняем → `navigate('Tasks')` из пушей (`use-notifications.ts`) и календаря теперь работает (раньше вложенные вкладки из корневого стека не открывались). Робот-уголок на «Сегодня» убираем — робот живёт на рабочем экране.

## Сервер: «покажи задачи» → открыть панель
Детерминированно, без ИИ (как деньги/задачи): `deterministicIntent` распознаёт «покажи/открой/выведи (мне) (мои) <задачи|дела|привычки|цели|финансы|расходы|бюджет|деньги|календарь|расписание|встречи|дневник|сегодня|день|сводку>» с необязательным хвостом «на сегодня/за неделю/за месяц» → `{ action: 'open_panel', panel }`, `panel ∈ today|tasks|habits|goals|finance|calendar|journal`. `handleMessage` отвечает коротко («Открываю задачи») и кладёт `openPanel` в `JarvisResponse`; `/voice/chat`, `/voice/process` отдают `openPanel`. Вопросы («сколько я потратил?», «какие задачи на сегодня?») этим НЕ ловятся — уходят в мозг как раньше.

## Мобилка
- `navigation/index.tsx`: вместо `Tabs` — `Home` (два экрана); панели — экраны корневого стека с `presentation: 'modal'` и заголовком. `useNotifications()` переезжает в `Home`.
- `app/home/index.tsx`: горизонтальный пейджер (`ScrollView pagingEnabled`, без новых нативных зависимостей), стартует на «Рабочем»; точки-индикатор.
- `app/home/room-page.tsx`: робот (большой), фон комнаты, подсветка по времени суток (как в прототипе), подсказка «Скоро здесь можно будет обставить комнату».
- Рабочий экран = текущий чат: робот крупно сверху (уменьшается, когда юзер пишет/говорит), шестерёнка настроек, кнопка «Инструменты» → чипы панелей (с учётом `ui-store`). Когда приходит ответ с `openPanel` — открываем панель.
- `services/panels.ts` (чистый, jest): `PANELS` (ключ → маршрут/подпись/иконка/фича-флаг), `panelRoute(key)`, `visiblePanels(isFeatureVisible)`.

## Тесты
- Сервер unit: `deterministicIntent` — 10+ фраз «покажи/открой» → правильная панель; вопросы и «покажи как …» → не open_panel.
- Сервер it: `/voice/chat` «Открой задачи» → `openPanel: 'tasks'`, ничего не создано.
- Мобилка jest: `panels.ts`; chat-store сохраняет `openPanel`; гард: в навигации нет `createBottomTabNavigator`, панели зарегистрированы как modal.

## Вне скоупа
Мебель/комната с расстановкой (Часть 4); перерисовка панелей под робота; открытие панелей из голосового пути дашборда (там уже есть свои экраны).
