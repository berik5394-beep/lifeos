# Робот-эпик, Часть 4: комната робота — мебель и расстановка

**Дата:** 2026-11-05 · **Решение Berik:** «Бесплатный набор, храним на сервере» · **Референс:** прототип `robot_companion.html` (каталог из 8 предметов, перетаскивание, долгий тап — убрать), заметка `robot_avatar_replaces_pet` (комната = дом робота, без уровней и прокачки; покупки — позже).

## Цель
Экран «Комната» (Часть 3) становится домом, который юзер обставляет сам: выбирает предмет из набора, ставит, двигает пальцем, убирает долгим нажатием. Расстановка хранится на сервере (не теряется при переустановке) и известна мозгу — робот может обсудить свою комнату в чате.

## Каталог (бесплатный, статичный, общий для клиента и сервера)
`plant 🪴 Растение`, `sofa 🛋️ Диван`, `picture 🖼️ Картина`, `lamp 💡 Лампа`, `books 📚 Книги`, `clock 🕰️ Часы`, `rug 🟫 Ковёр`, `plush 🧸 Игрушка`. Один и тот же предмет можно поставить несколько раз. Максимум 30 предметов в комнате.

## Сервер
- Модель `RoomItem { id, userId → User (onDelete Cascade), itemKey, x Float 0..1, y Float 0..1, createdAt }`, индекс по userId; миграция `20261105020000_room_items` (идемпотентная).
- `GET /room` → `{ items: [{ id, itemKey, x, y }] }`.
- `PUT /room` `{ items: [{ itemKey, x, y }] }` — заменяет всю расстановку в транзакции (deleteMany + createMany). Валидация: itemKey из каталога, x/y в [0,1], ≤ 30 предметов. Удаление аккаунта — каскадом.
- Мозг: строка в контексте `"Комната робота: диван, лампа, растение ×2"` (только если есть предметы; READ-ONLY), чтобы на «как тебе комната?» робот отвечал по факту, а не выдумывал. Захват в память не нужен.

## Мобилка
- `services/room-catalog.ts` (чистый, jest): `ROOM_CATALOG`, `isRoomItemKey`, `clampToRoom(x, y)`.
- `stores/room-store.ts`: `items`, `fetchRoom()`, `addItem(key)` (в центр), `moveItem(id, x, y)`, `removeItem(id)`; сохранение на сервер `PUT /room` с задержкой 600 мс после изменения (не на каждый кадр перетаскивания); сбой сети — изменения остаются локально, повтор при следующем изменении.
- `app/home/room-page.tsx`: предметы позади робота (комната живёт за ним), перетаскивание — `react-native-gesture-handler` Pan (уже в проекте), долгое нажатие — убрать с подтверждением-вибрацией; внизу полоса каталога «Обставить: 🪴 🛋️ …». Робот радуется (`happy`) на новый предмет. Голова иногда поворачивается — комната сзади чуть сдвигается в противоход (параллакс, как в прототипе).

## Тесты
- Сервер it: GET пустой; PUT → GET тот же набор; PUT заменяет целиком; невалидный itemKey/x>1/31 предмет → 400; чужой юзер не видит; удаление аккаунта стирает.
- Сервер unit: строка контекста комнаты (группировка ×N, пусто → null).
- Мобилка jest: каталог/clamp; room-store add/move/remove + отложенное сохранение (fake timers) + один PUT на серию движений.

## Вне скоупа
Покупки (IAP), новые предметы с сервера, уровни/эволюция комнаты (отменены Berik), стены/обои.
