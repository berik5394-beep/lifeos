## Что уже есть (основа, 2026-11-07)

- Одна голова на всё: задачи, траты, привычки, встречи, сделки, люди, дневник —
  через один мозг (jarvis-orchestrator).
- Память о человеке: факты, близкие и связи; «мама переехала» заменяет старое;
  два брата не сливаются; портрет «Каким я тебя вижу».
- Пишет сам: напоминания о встречах, «Завтра» в 20:00, утренний бриф, «как ты?»,
  детекторы (давно не звонил важному, ДР, трата ест цель).
- Связывает разделы: траты↔цель, сон↔задачи, тип человека↔каденс↔деньги.
- Честность: не выдумывает (гард чисел, замер в чате), деньги — только после
  «да», ход не висит дольше 48 с.

## Пункты

### 1. Бриф перед встречей — ✅ 2026-11-07
За час до встречи: «Через час Серик. Ты обещал ему прайс, он должен тебе
200 000, в прошлый раз обсуждали турникеты для склада».
- [x] Сбор фактов о человеке со встречи (person-types/meeting-impl.ts):
      твоё обещание / обещали тебе (раздельно), тебе должны / за тобой долг,
      открытая сделка, «Помню: …» — последняя действующая запись памяти о нём.
- [x] Пуш за час «Через час: <встреча>» с брифом (proactive-notifications.ts);
      ранний бриф облачком — за 3 ч…75 мин, без двух сообщений об одном.
- [x] Честно: о человеке ничего нет / «Неправда» в памяти — обычное напоминание.
- [x] Тесты (meeting.test, meeting-brief-push.it) + прод.
- Дальше (не обязательно): бриф голосом при открытии приложения перед встречей;
  встречи без известного человека — связанные задачи/письма.

### 2. Взгляд сверху — ⬜
«Три недели тушишь пожары, а годовая цель стоит — вернись к главному».
Раз в неделю: куда ушло время/силы против годовых целей.

### 3. Время = деньги и команда — ⬜
«Это совещание стоит 2 часа твоего времени — отдай Айгуль». Робот знает цену
часа и команду, предлагает делегировать.

### 4. Руки во внешнем мире — ⬜
Отправить письмо, забронировать, оплатить, позвонить — за пользователя (с «да»).
Сейчас почта и календарь в основном на чтение.

### 5. Голос как у Джарвиса — ⬜
«Привет, ЛайфОС» без рук, почти мгновенный ответ (сейчас — держи кнопку,
ответ за несколько секунд).

### 6. Жизнь на реальных данных — 🟡
Робот «знает» человека, когда накопит месяц-два жизни. Пользоваться каждый день
2–3 недели и чинить реальные промахи. Дыра «память пустая» закрыта 2026-11-07
(18be138); замер выдуманных чисел — разбор логов 2026-11-14.
