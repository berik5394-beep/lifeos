## Что уже есть (основа, 2026-11-07)

- Одна голова на всё: задачи, траты, привычки, встречи, сделки, люди, дневник —
  через один мозг (jarvis-orchestrator).
- Память о человеке: факты, близкие и связи; «мама переехала» заменяет старое;
  два брата не сливаются; портрет «Каким я тебя вижу».
- Пишет сам: напоминания о встречах, «Завтра» в 20:00, утренний бриф, «как ты?»,
  детекторы (давно не звонил важному, ДР, трата ест цель).
- Связывает разделы: траты↔цель, сон↔задачи, тип человека↔каденс↔деньги.
- Честность: не выдумывает (гард чисел, замер в чате), деньги — только после
  «да», ход не висит дольше 48 с.

200 000, в прошлый раз обсуждали турникеты для склада».

      открытая сделка, «Помню: …» — последняя действующая запись памяти о нём.
- [x] Пуш за час «Через час: <встреча>» с брифом (proactive-notifications.ts);
      ранний бриф облачком — за 3 ч…75 мин, без двух сообщений об одном.
- [x] Честно: о человеке ничего нет / «Неправда» в памяти — обычное напоминание.

- Дальше (не обязательно): бриф голосом при открытии приложения перед встречей;

### 2. Взгляд сверху — ✅ 2026-11-08
«Три недели тушишь пожары, а годовая цель стоит — вернись к главному».
- [x] Факты за 3 недели (services/strategic-view.ts): закрытые задачи; шаги к
      цели года только по реальным связям (задача → цель недели → цель года,
      задача → цель года, отметки привычек, привязанных к цели); трогали ли
      прогресс цели.
- [x] Говорит, только если: цели есть, дел закрыто ≥ 6, шагов к целям ≤ 10%,
      есть цель без единого шага (из таких — с меньшим прогрессом). Цель,
      поставленная на днях, «стоящей» не считается.
- [x] Сигнал робота strategic_drift: только в воскресенье, не чаще раза в 7 дней
      на цель; пуш тем, у кого уведомления, облачко — остальным; глушится при
      тяжёлом настроении (как остальные «давящие»).
- [x] Тесты (strategic-view.test, strategic-view.it) + прод.
- Дальше: ответ на «скажи какой шаг» — задача сразу привязывается к цели
  (сейчас создастся задача, но без связи с целью); фраза о курсе в «Итогах
  недели».

### 3. Время = деньги и команда — ✅ 2026-11-08
«Это совещание стоит 2 часа твоего времени — отдай Айгуль».
- [x] Цена часа (services/time-value.ts): названная — инструмент set_hour_rate
      («мой час стоит 20 000» → settings.hourRate); иначе оценка по доходу за
      3 месяца / 160 ч, честно «примерно, по доходу»; дохода нет — молчим.
- [x] Команда: set_person_type с типом team + role («Айгуль — наш бухгалтер»);
      русские слова → тип; команда не попадает в «давно не связывался».
- [x] «Завтра» в 20:00: самая длинная встреча (≥1,5 ч) с ценой твоего времени
      + до 2 «Сверить акты» — по части Айгуль (бухгалтер). Передать?» — по словам
      роли/имени, без совпадения — без строки.
- [x] Мозг знает цену часа и команду (контекст) — «стоит ли мне идти?», «кому
      отдать?»; передача — только с «да».
- [x] Тесты (time-value.test, time-value.it) + прод.
- Дальше: «передать» = реальное поручение человеку (письмо/Telegram — это №4);
  экран «Команда» в приложении; роли без словаря — через ИИ.

### 4. Руки во внешнем мире — 🟡 письма ✅ 2026-11-08
Отправить письмо, забронировать, оплатить, позвонить — за пользователя (с «да»).
- [x] Письма через Gmail пользователя: инструмент send_email (needsConfirm,
      external) — робот пишет черновик (кому, тема, текст), отправка только
      после «да». Получатель — адрес или имя человека из памяти

- [x] Заодно: экран интеграций не видел подключённый Google и «Отключить»
