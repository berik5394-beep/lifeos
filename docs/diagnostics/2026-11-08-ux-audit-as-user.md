## Как проверял

- **Устройство:** iPhone 14 (Berik) через Видеоповтор, сборка №20, аккаунт «Лейла» (почти пустой: 1 задача, 1 расход, 0 привычек, 0 целей — идеально для взгляда новичка), тема «Розовая».
- **Ограничение:** через Видеоповтор работают только тапы. Прокрутка и свайпы внутри приложения — нет. Поэтому всё, что ниже первого экрана и за свайпом (комната робота, настройки), сверено по коду, не глазами. Такие пункты помечены **[код]**. Остальное — **[экран]**, увидено вживую.
- **Прошёл вживую:** Сегодня (первый экран), Задачи → Дашборд / Неделя / Итоги, Канбан, Таймлайн, Фокус, Сделки, Привычки → Обзор / Календарь / Аналитика, Цели, Финансы → Обзор.
- **Не дошёл (телефон был занят, видеоповтор рвался):** вкладки Календарь и Дневник, кнопки «Камера», «Отбой», «Разбор», тап по роботу, ввод текста роботу, комната, настройки, онбординг, вход.

Серьёзность: 🔴 — пользователь не найдёт или не поймёт ключевое; 🟠 — путает, выглядит сломанным; 🟡 — шероховатость.

## По экранам

### 1. «Сегодня» (первый экран после входа) — [экран]

Что видно на iPhone 14 без прокрутки: приветствие, цитата, кольцо «Прогресс дня 0 из 0», три карточки (Задачи 0/0, Привычки 0/0, Настроение —), 7 кнопок, заголовок «Планер» и лента недели. Дальше — только прокруткой: задачи дня, цели недели, тепловая карта года, аналитика.

- 🔴 **Пустой аккаунт — и ни одного призыва к действию на первом экране.** «0 из 0 выполнено», «0/0», «—». Новичок не понимает, с чего начать. Строка «Новая задача» — под лентой недели, ниже сгиба. (`index.tsx:520-566`)
- 🟠 **Карточка «Настроение —» не выглядит нажимаемой**, а по тапу раскрывает ряд смайликов. Нет ни стрелки, ни подписи «отметить». (`index.tsx:560-581`)
- 🟠 Цитата: тёмная карточка (см. главное №8). Кнопка «🔊» справа — непонятно, что она озвучит цитату; иконка-эмодзи, не кнопка.
- 🟡 Приветствие «Доброе утро, Лейла!» крупным шрифтом и сразу под ним цитата — два «декоративных» блока занимают четверть экрана до первой цифры.
- 🟡 Лента недели: «Пн 2» перекрыт роботом (главное №7). Выбранный день подсвечивается рамкой — ок; но что тап по дню фильтрует задачи ниже — не видно, т.к. список ниже сгиба.
- 🟡 Кнопка «Разбор» одна на всю ширину с красным фоном (`#EF4444 + 30`) — читается как предупреждение. (`index.tsx:631`)
- 🟡 «Камера» → на самом деле «сфотографируй список/расписание — AI вытащит задачи» (`app/task-capture.tsx:260`). Название не передаёт смысл.
- 🟡 «Отбой» → вечерний ритуал робота (`index.tsx:625`). Для новичка слово ничего не значит днём.
- 🟡 Утреннее приветствие (`components/voice/morning-greeting.tsx`) с чипами «Планы на сегодня / Встречи / Бюджет / Мотивация / Спросить голосом» — не видел вживую (уже было показано сегодня). Отмечу: это **третий** набор кнопок-подсказок (вкладки, 7 чипов, утренние чипы) на одном экране.

## Сквозные проблемы

1. **Глубина навигации.** Дом → вкладка → подвкладка-вид → подвкладка-слайд → (Канбан) вкладки колонок. До четырёх полос табов. Пользователь теряет, где он.
2. **Невидимые жесты без обучения на месте:** свайп в комнату, свайп на «Сегодня», сдвиг строки влево для удаления, долгое нажатие на мебель, двойной тап на комнату, удержание микрофона. Подсказки текстом 12 px и один раз.
3. **Нулевые данные подаются как результат:** «100 %», «Продолжай!», «Критично», «−2 500 накопление», «Все задачи выполнены». Новичок видит оценки там, где ещё нечего оценивать.
4. **Дубли входов:** Дневник ×3, Разбор ×2, Календарь ×2, сон/настроение ×2.
5. **Тон:** «ты» и «Вы» вперемешку (Фокус, онбординг, вход, пустые состояния «Создайте»).
6. **Цвет не из темы:** карточка цитаты `#1A2540`, кнопка «Разбор» `#EF4444`, донаты и статусы Канбана с фиксированными hex — на розовой теме выбиваются.
7. **Робот поверх контента** без своей полосы — перекрывает первую колонку/легенду/иконку внизу слева на каждой вкладке.
8. **Полоса вкладок и точки пейджера** — единственная ориентация «где я», и обе слабые (обрезка + невидимая точка).
