## 🎯 Headline
Бот **не источник чисел** в большинстве мест (это хорошо — архитектура «считает код, подставляет код» в основном соблюдена). Галлюцинация фактов идёт по **двум разным механизмам**, и есть **6 ЖИВЫХ дыр**, доходящих до юзера сегодня.

- **Механизм M1 — Шаблонный слой без валидации слота.** Число/имя считает код, но рендер не проверяет КАЖДЫЙ слот → пустое «»/сентинел/абсурд уходит юзеру.
- **Механизм M2 — Свободная генерация без привязки к контексту.** Модель пишет прозу (чат/утро/ночь/синтез) и НЕ обязана брать факты только из данных → выдумывает счётчики/числа.
