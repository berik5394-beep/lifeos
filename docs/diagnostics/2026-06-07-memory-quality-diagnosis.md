# Память — диагностика качества (приоритет №1)

> Дата: 2026-06-07. Метод: 4 параллельных read-only разбора кода (extraction / forgetting / enrichment+cross-domain+calendar / legacy) + синтез. Прод-данные НЕ читались (только код). Это диагноз, НЕ фиксы. Фиксы — отдельно, по порядку, по слову Berik.

## 🎯 ГЛАВНЫЙ ВЫВОД (headline)

**Машинерия качества ПОСТРОЕНА — выключатели НЕ включены.** Большая часть инфраструктуры для «точность + забывание + персона + честный кросс-домен» уже написана в v2, но **никогда не подключена**:
- **Забывание есть в коде, но выключено:** `invalidateEvent` (0 вызовов), `invalidateStale` для паттернов (0 вызовов), скрипт `dedup-entities` (только руками), `invalidAt` на связях (всегда `null`). Система «умеет забывать», но забывание не запущено → почти всё живёт вечно.
- **Алиасы/коререференс есть, но мертвы:** слой `resolveEntity` (alias-FTS) + alias-merge написан, но **экстрактор не выдаёт `aliases`** → «Серик/Серика/Сериком» = 4 разных сущности, весь слой склейки — мёртвый код.
- **Персона построена, но не доходит до промпта:** `formatAxesSection` + `formatToneSection` (характер юзера + тон бота) **НИКОГДА не добавляются в system-промпт**. Весь axes/bot-traits слой не влияет на ответы.
- **Честный кросс-домен есть рядом, но захардкожен:** `goalsBehind: 0` литералом в reflector-v2, хотя реальный расчёт целей уже есть в `reflector-service`.

→ Хорошая новость: чинить = в основном **подключать готовое**, а не строить заново.

## ✅ ЛЕГАСИ — ЧИСТО (твой акцент «ни какой легаси»)

Живого легаси НЕТ. Подтверждено:
- `UserProfile` полностью удалён (миграция `20260606000000_drop_user_profile` + гард-тест `phase6-schema.test.ts:66`). 0 ссылок в коде.
- Единый писатель `writeMemory` — единственный путь записи; `captureMemory` удалён. Чтение — единый `Memory` (FTS+pgvector).
- Live chat-пайплайн (jarvis-orchestrator) пишет ТОЛЬКО через v2; флаг-OFF ветка — тоже v2 (тоньше), не легаси, и в проде недостижима (FEATURE_V2_*=all).
- `parseIntent` — это intent-роутер (не память), оставлен намеренно (booking/money-prefilter).
- **Остаточная гигиена (не легаси, косметика):** устаревшие комментарии «legacy/dual-write» в `v2-capture.ts:1-11`, `memory-service.ts:119`, `feature-flags.ts:308` (врут, что легаси-пайплайн ещё есть — его нет) + 3 мёртвых-но-v2 экспорта (`invalidateEvent`, `getEventsForEntity`, `entityFrequency` в `episodic-memory.ts`). Мёртвые экспорты — это как раз «выключенные выключатели» (см. забывание).
